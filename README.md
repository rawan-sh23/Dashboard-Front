# Madar Tech Dashboard

A dynamic admin dashboard designed to manage the "Madar Tech" website content effortlessly, allowing administrators to update texts, colors, and dynamic sections without touching the code.

## Features
- Theme Customization: Instantly change the website's primary colors, accent colors, text colors, and backgrounds.
- Content Management: Edit Hero section titles, descriptions, and "About Us" texts dynamically.
- Dynamic Sections: Easily add, edit, or remove Services and Training Programs.
- Real-time Updates: All changes are saved to localStorage and instantly reflected on the main website upon refresh.
- User-Friendly UI: Clean, responsive, and easy-to-use interface.

## Tech Stack
- HTML5 & CSS3 (Dashboard layout and styling).
- Bootstrap 5 (For responsive and structured UI).
- JavaScript (Vanilla): For managing state, handling arrays (Services/Programs), and interacting with localStorage.
- Font Awesome & Google Fonts.
